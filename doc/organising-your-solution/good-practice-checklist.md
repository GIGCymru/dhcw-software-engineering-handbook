# Good practice checklist

Use this checklist to demonstrate you follow our coding standards.

We cross-reference each checklist item to a relevant section in our
standards and guides; Exceptions are noted where they may apply.

## Folder structure good practice

| **Item** |  |  | **Guide or standard** | **Exceptions** |
| --- | --- | --- | --- | --- |
| 1 | You use physical folders to separate logical areas of your software solution | ☐ | [*Use physical folders*](follow-our-folder-and-file-conventions.md#use-physical-folders) |  |
| 2 | You include a README markdown file, instructing others on how to build and deploy your software solution | ☐ | [*Provide a README file*](follow-our-folder-and-file-conventions.md#provide-a-readme-file) |  |
| 3 | You include a .editorconfig to allow your code style rules to be shared | ☐ | [*Provide a .editorconfig file*](follow-our-folder-and-file-conventions.md#create-a-editorconfig-file) |  |
| 4 | You include a *source* folder | ☐ | [*Include a source folder*](recommended-solution-sub-folders.md#create-a-source-folder) |  |
| 5 | You create subfolders to separate dependency layers | ☐ | [*Use additional subfolders for dependency layers*](recommended-solution-sub-folders.md#use-additional-sub-folders-for-dependency-layers) |  |
| 6 | You include a *documents* folder | ☐ | [*Include a documents folder*](recommended-solution-sub-folders.md#provide-a-documents-folder) |  |
| 7 | You document significant architecture decisions, including deliberate technical debt, using an ADR stored in a decision records folder | ☐ | [*Include a decision records (ADRs) folder*](recommended-solution-sub-folders.md#include-a-decision-records-adrs-folder) | Not applicable if no significant decision has been made |
| 8 | You include folder for coded tests | ☐ | [*Include a test folder*](recommended-solution-sub-folders.md#provide-a-test-folder) |  |
| 9 | You include a *builds* folder | ☐ | [*Include a build folder*](recommended-solution-sub-folders.md#provide-a-build-folder) |  |
| 10 | You include a *deploy* folder | ☐ | [*Include a deploy folder*](recommended-solution-sub-folders.md#provide-a-deploy-folder) | May only be required if deploying to cloud |
| 11 | You provide examples with your solution | ☐ | [*Include an examples folder*](recommended-solution-sub-folders.md#provide-an-examples-folder) |  |
